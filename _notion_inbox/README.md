# 노션 인입함 (_notion_inbox)

노션 글을 블로그로 옮길 때 쓰는 **임시 작업 폴더**.

## 쓰는 법
1. 노션 페이지에서 `⋯ → Export → Markdown & CSV` → zip 다운로드
2. **zip 이름을 원하는 블로그 글 제목으로 바꾸기.** 이 이름이 그대로 글 title이 된다.
   - 노션 기본 이름은 `Export-a1b2c3….zip`이라 제목이 없음 → 반드시 rename.
   - 예: `[회고] 25년 12월 2주차.zip` → title `[회고] 25년 12월 2주차`
   - 접두(`[회고]`, `[운영체제]` 등)로 카테고리·slug도 자동 판별됨.
3. 그 **zip**(또는 압축 푼 폴더)을 이 폴더 안에 넣기
4. Claude에게 **"인박스 발행해줘"** (또는 `/new-post`) 라고 요청

그러면 자동으로:
- zip/폴더 이름 → title, 접두 → 카테고리/slug 판별 (slug 충돌 시 번호 자동)
- 이미지를 `assets/img/posts/<slug>/`로 이동 + `image.png`, `image 1.png` … 규칙으로 이름 정리
- 본문 이미지 경로 전부 새 경로로 치환, 노션 속성줄·중복 제목 등 정리
- front matter 생성 → 커밋 → push

## 주의
- 이 폴더 안의 실제 export 파일은 `.gitignore` 처리되어 **커밋되지 않는다** (이 README만 추적됨).
- 발행 끝나면 인입함 안의 원본 폴더/zip은 지워도 된다.
